■ 2. 弾幕スクリプトの基本構文ルール
--------------------------------------------------------------------------------
1. 【波括弧スタイル推奨】
   `while (true) { ... }` や `repeat(10) { ... }` のように波括弧 `{ }` で囲みます。
2. 【コメント】
   `// ここはコメント` の形式で1行コメントを書けます。
3. 【変数の宣言・代入】
   `angle = 0`
   `speed = 200`
   `val += 5`（加算） / `val -= 5`（減算）
4. 【待機（ウェイト）】
   `wait(0.1)` : 0.1秒待機（while (true) などの無限ループ内には必ず wait を入れること！）
5. 【ループ構文】
   ・指定回数ループ:
     `repeat(12) { ... }` または `for (let i = 0; i < 12; i++) { ... }`
     ※多重ループ（ネスト）時は `for (let i = 0; ...)` と `for (let j = 0; ...)` のように変数名を変えてください。
   ・無限ループ:
     `while (true) { ... }` または `forever() { ... }`
   ・条件付きループ:
     `while (count < 10) { ... }`
6. 【条件分岐構文】
   ・通常IF:
     `if (second >= 5.0) { ... }`
   ・一度だけ実行（ONCE）:
     `once { ... }`（弾やエミッタの生存期間中に1度だけ実行）
   ・範囲条件（レンジ）:
     `if (frame == 10..60) { ... }`（10〜60フレームの間）
     `if (second == 2.0..4.0) { ... }`（2〜4秒の間）
   ・周期条件:
     `if (cardSecond == 5 * n) { ... }`（5秒、10秒、15秒…ごとに発動）
   ・並列実行（並列スレッド）:
     emitterScript 内で複数の `while (true) { ... }` を並べて書くと、自動的に並列動作します。

■ 3. 弾の生成コマンド（全種類一覧）
--------------------------------------------------------------------------------

★ 【最新・推奨】 統一弾生成関数: bullet(...)
あらゆる種類の弾（通常弾、トレイル弾、レーザー、耐久値つき life 弾）を柔軟に生成でき、
自作の変数を弾に持たせることも可能です。引数はオブジェクトの並び、または単一オブジェクトで自由に指定できます。

構文例（複数オブジェクト形式）:
bullet({"type":"life"},{"image":"redscale"},{"speed":200},{"angle":angle},{"radius":6},{"hitRadius":6},{"isAbsolute": false},{"x":0},{"y":0},{"color": "rgb(255, 0, 0)"},{"health":200},{"自作の変数1":10},{"自作の変数2":"aaa"})

構文例（単一オブジェクト形式・省略可能）:
bullet({ type: "life", image: "star", speed: 200, angle: angle, health: 300, myScore: 100 })
bullet({ type: "trail", speed: 180, angle: 45, color: "#ffff00", growTime: 0.2, keepTime: 0.3, shrinkTime: 0.5, round: true })
bullet({ speed: 250, angle: angle, color: "#00ffff" }) // 省略時は type: "normal"

構文例（全方位弾 & Way弾）:
bullet({ "way": 50, speed: 200, angle: angle }) // 全方位50発（Ring弾）
bullet({ "way": 5, "distance": 6, "distancetype": "step", angle: angle }) // 弾同士の間隔6度ずつの5way弾
bullet({ "way": 5, "distance": 60, "distancetype": "total", angle: angle }) // 全体60度幅に広がる5way弾
bullet({ "type": "life", "way": 16, "health": 200, "image": "redscale" }) // 全方位16発の耐久弾

【対応プロパティ】
・type        : "normal" / "trail" / "laser" / "life" (デフォルト: "normal")
・image       : 弾画像名（"kome", "star", "redscale" 等。normal, life のみ有効）
・speed       : 弾速 (デフォルト: 200)
・angle       : 発射角度 / 中心角 (デフォルト: 0 または現在の angle)
・way         : 発射弾数 (デフォルト: 1)。1より大きいとき複数弾を同時発射
・distance    : 拡散角度幅 または 弾同士の間隔 (度数法)。指定なしなら全方位(360度)
・distancetype: "step"（弾同士の間隔） / "total"（全体の角度幅、デフォルト）
・radius      : 見た目の半径 (デフォルト: 6)
・hitRadius   : 当たり判定半径 (デフォルト: radius と同じ)
・isAbsolute  : false (相対座標) / true (絶対座標)
・x, y        : 発射オフセット / 座標
・color       : 色 ("#ff0000" や "rgb(255, 0, 0)")
・health      : 耐久値（type: "life" の場合のみ有効。デフォルト: 200）
・destroyResist: 弾消し耐性（true / false。ボムや被弾時の即死弾消しを防ぐ）
・growTime, keepTime, shrinkTime, round : トレイル用パラメータ（type: "trail" の場合）
・自作変数    : {"自作変数名": 値} を指定すると、その弾の bulletScript 内で初期値として使用可能。

【life 弾（耐久値つき弾）の仕様】
・基本は通常弾と同じ挙動をしますが、自機ショットが当たると攻撃を吸い込み（自機ショット消滅）、
  ダメージを受けて HP が減少します。
・ボムの衝撃波の範囲内に入るとボムの持続ダメージを受けます。
・HP が 0 になると破壊されて静かに消滅します（弾消し耐性 destroyResist が付いていても HP 破壊は有効です）。
・弾スクリプト（bulletScript）内で `if (isDestroyed)` または `if (destroyed)` を使うことで、
  「弾が破壊された瞬間に分裂弾をばら撒く」「効果音を鳴らす」などの処理が可能です！

例 (破壊された瞬間に分裂する耐久弾):
bulletScript: `
if (isDestroyed) {
    spawnRing("normal", "#ffff00", 160, 0, 8, 0, 0, 6, "star", "relative", 6)
    playSound("break")
}
`

■ 敵HP（ボスHP）の参照と直接操作
--------------------------------------------------------------------------------
【ボスHPのデフォルト】: 1000 （カード作成画面のボスHP初期値）

【変数】
・enemyHp    : 敵ボスの現在HP（参照および直接書き換え可能）
・enemyMaxHp : 敵ボスの最大HP（参照用）

【スクリプトからの敵HP直接操作】
エミッタースクリプトや弾スクリプト内で、敵HPを直接代入・加減算できます：
```javascript
// 敵HPを直接500に設定
enemyHp = 500

// 敵HPを直接100減らす（ダメージを与える）
enemyHp -= 100

// 敵HPに応じた弾幕フェーズ分岐
if (enemyHp <= 500) {
    spawnRing("normal", "#ff0000", 250, angle, 24)
}
```

◆ 1. 直線弾・単発弾の生成 (従来形式)
spawnStraight(bulletType, color, speed, angle, offsetX, offsetY, radius, bulletImage, coordMode, hitRadius)
（※ spawnBullet も同等）
例: spawnStraight("normal", "#ff3344", 200, angle, 0, 0, 8, "star", "relative", 6)

◆ 2. 全方位リング弾（全方位弾）の生成
spawnRing(bulletType, color, speed, angle, count, offsetX, offsetY, radius, bulletImage, coordMode, hitRadius)
例: spawnRing("normal", "#33aaff", 180, angle, 16, 0, 0, 20, "ohuda", "relative", 6)
・count: 発射数（例: 16発）
・angle: 基準角度（自機狙いや回転角度）

◆ 3. 扇状弾（Way弾）の生成
spawnWay(bulletType, color, speed, angle, count, spread, offsetX, offsetY, radius, bulletImage, coordMode, hitRadius)
例: spawnWay("normal", "#ffcc00", 220, angle, 5, 45, 0, 0, 16, "kome", "relative", 6)
・count: 弾数（奇数推奨: 3, 5, 7...）
・spread: 全体の拡散角度（例: 45度幅）

◆ 4. トレイル弾（軌跡弾・レーザー風）の生成
spawnTrail(color, speed, angle, offsetX, offsetY, radius, growTime, keepTime, shrinkTime, round, coordMode, hitRadius)
例: spawnTrail("#00ffff", 200, angle, 0, 0, 8, 0.2, 0.3, 0.5, true, "relative", 6)
・growTime: 伸びる時間 (秒)
・keepTime: 維持時間 (秒)
・shrinkTime: 縮んで消える時間 (秒)
・round: 先端を丸くするか (true / false)

◆ 5. 極太ビーム（警告線あり貫通レーザー）の生成
spawnBeam(warningTime, activeTime, laserWidth, angle, offsetX, offsetY, coordMode, hitRadius)
例: spawnBeam(1.0, 1.5, 24, angle, 0, 0, "relative", 12)
・warningTime: 予告線（赤細線）の表示秒数（例: 1.0秒）
・activeTime: ビーム照射時間（例: 1.5秒）
・laserWidth: ビームの太さ（例: 24px）

◆ 6. レーザーWay弾 / レーザーリング弾
spawnLaserWay(color, radius, speed, angle, count, spread, offsetX, offsetY, growTime, keepTime, shrinkTime, round, coordMode, hitRadius)
spawnLaserRing(color, radius, speed, angle, count, offsetX, offsetY, growTime, keepTime, shrinkTime, round, coordMode, hitRadius)

◆ 7. 極太ビームWay / ビームリング
spawnBeamWay(warningTime, activeTime, laserWidth, angle, count, spread, offsetX, offsetY, coordMode, hitRadius)
spawnBeamRing(warningTime, activeTime, laserWidth, angle, count, offsetX, offsetY, coordMode, hitRadius)

◆ 8. 魔法陣（子機）の生成
spawnMagicCircle(color, offsetX, offsetY)
※ 生成された魔法陣は magicCircleScript に従って弾を撃ちます。

■ 5. 移動・制御・アニメーションコマンド
--------------------------------------------------------------------------------
◆ 1. 自機狙い（角度計算）
aimAtTarget()
・現在の発射元から相手（自機）の方向を計算し、変数 `angle` に自動代入します。

◆ 2. 指定座標狙い
aimAt(x, y)
・指定した座標 (x, y) の方向を変数 `angle` に代入します。

◆ 3. ボス/発射元の移動
moveTo(x, y) または moveTo("center")
slideTo(x, y, duration)
・`slideTo(384, 200, 1.5)` : 1.5秒かけて (384, 200) に滑らかに移動。

◆ 4. スムーズな数値遷移（Tween）
tween("変数名", 開始値, 終了値, モード, 時間/ステップ, イージング)
・モード:
  "seconds" : 指定秒数かけて遷移（例: `tween("angle", 0, 360, "seconds", 2.0, "easeInOut")`）
  "step"    : 毎フレーム固定値加算（例: `tween("x", 100, 600, "step", 2)`）
  "vecstep" : ベクトル等速直線移動
・イージング: "linear", "easeIn", "easeOut", "easeInOut"

◆ 5. 弾専用の制御コマンド（bulletScript内で使用）
・bounce()           : 画面端（壁）に当たった時に反射する
・homing(旋回速度)   : 相手に向かって旋回追尾する（例: `homing(90)`）
・slow(倍率, 遅延秒) : 弾速を減速する（例: `slow(0.3, 0.5)` : 0.5秒後に速度0.3倍）
・fast(倍率, 遅延秒) : 弾速を加速する（例: `fast(2.0, 1.0)` : 1.0秒後に速度2倍）
・advance(距離)      : 現在の角度方向に指定px瞬間前進

■ 6. スクリプト内で使える組み込み変数と関数
--------------------------------------------------------------------------------
【組み込み変数】
  second      : 発生からの経過時間（秒）
  frame       : 発生からの経過フレーム数 (60フレーム=1秒)
  cardSecond  : スペルカード全体の経過時間（秒）
  cardFrame   : スペルカード全体の経過フレーム数
  x, y        : 現在座標 (画面幅 768, 高さ 896)
  angle       : 進行角度（0度:右, 90度:下, 180度:左, 270度:上）
  speed       : 現在の移動速度
  dist        : 自機（ターゲット）との直線距離
  tx, ty      : 自機（ターゲット）の現在座標
  ex, ey      : 発射元（ボス）の現在座標

【弾専用の変数（bulletScript内）】
  color       : 弾のカラーコード（例: "#ff3344"）
  radius      : 弾の見た目のサイズ半径
  hitRadius   : 当たり判定の半径（0にすると無害な飾り弾になる）
  spriteAngle : 画像スプライトの回転角度（`spriteAngle = angle` で進行方向を向く）
  timer       : その弾が生まれてからの経過秒数
  isBounced   : 画面端に反射した瞬間 1 になる
  touchingWall: 壁に接触中 1 になる
  isTouchBullet: 他の弾と接触した瞬間 1 になる
  e_変数名    : emitterScript で設定した変数を弾側からリアルタイム参照（例: `e_phase`）

【組み込み数学関数】
  sin(deg), cos(deg), tan(deg) : 三角関数（※角度は度数法 0〜360度）
  atan2(y, x)                  : 逆正接
  sqrt(v), pow(a, b), abs(v)   : 平方根、べき乗、絶対値
  min(a, b), max(a, b)         : 最小値、最大値
  floor(v), ceil(v), round(v)  : 切り捨て、切り上げ、四捨五入
  rand(min, max)               : 指定範囲の乱数を取得（例: `rand(-15, 15)`）
  seedrandom[seed](min, max)   : シード値固定の乱数

■ 8. ゲームへの反映方法（超重要！）
--------------------------------------------------------------------------------
1. 【S2弾幕】を作成したら `js/danmaku2.js` に追加して保存します。
2. フォルダ内の 【compile.bat】 をダブルクリック（またはコマンドプロンプトで `node tools/compile.js`）を実行します。
3. 自動的に `js/compiledanmaku.js` が生成・更新され、ブラウザでゲーム（index.html）を再読み込みすれば即座にプレイできます！
