自作カード管理

Scratch風のエディットでオリジナルのスペルカードを作成できます。
作ったカードは「弾幕をプレイ」で確認し、すぐに登録可能です。

基本構文・制御
// 指定回数の繰り返し (iを変更可能)
for (let i = 0; i < 10; i++) { ... }

// 無限ループ (ゲーム中ずっと実行)
while (true) { ... }

// 条件付きループ
while (条件) { ... }

// 条件分岐
if (条件) { ... }

// 弾の生存期間中に1回だけ実行 (弾側のみ)
once { ... }

// 指定秒数待機する
wait(0.5)

一番上の階層に複数のループを書くと、それらは並行して同時に動きます。

コア (Emitter) & 魔法陣の命令
// 弾を単発発射
spawnBullet("型", "色", 速度, 角度, Xオフセット, Yオフセット, 半径, "画像", "座標モード", 判定半径)

// 弾を全方位(リング状)に発射
spawnRing("型", "色", 速度, 弾数, Xオフセット, Yオフセット, 半径, "画像", "座標モード", 判定半径)

// 弾を扇状(Way)に発射
spawnWay("型", "色", 速度, 角度, 弾数, 拡散角, Xオフセット, Yオフセット, 半径, "画像", "座標モード", 判定半径)

// 魔法陣を生成 (魔法陣スクリプトが動きます)
spawnMagicCircle("色", Xオフセット, Yオフセット)

// ターゲットの方向を向く (angle に代入)
aimAtTarget()

// 座標の瞬間移動 / スライド移動
moveTo("位置") または slideTo("位置", 秒数)
※ 位置: "center", "left", "right", "farLeft", "farRight", "leftUp", "rightUp"

// 変数の非同期移行 / 移行完了まで待機
tween("変数名", 開始, 終了, "秒/フレーム/加算", 値)
tweenWait("変数名", 開始, 終了, "秒/フレーム/加算", 値)
※時間モード: "seconds", "frames", "step"
弾 (Bullet) の命令
// 速度・角度・色・レーザー幅を変更
speed = 200      // 速度を固定
speed += 10      // 加速
angle += 2       // 曲がる
spriteAngle += 5 // 画像だけ回転 (見た目のみ)
color = #ff3333  // 色変更
laserWidth = 16  // レーザー幅

// ターゲットの方向に向き直す
aimAtTarget()

// 毎秒指定の度数で追尾(ホーミング)
homing(90)

// 画面外の壁で跳ね返る
bounce()

// 速度の乗算変化 (倍率, 遅延秒数)
fast(2.0, 0.5)  // 0.5秒後に2倍速
slow(0.5, 0.2)  // 0.2秒後に半減

// レーザー予告線と実体化の設定
warningTime = 1.0  // 予告1秒
activeTime = 1.5   // 実体化1.5秒
laserWidth = 12    // 幅12px
組み込み変数と衝突判定
// --- 共通変数 ---
angle, speed   // 角度、速度
spriteAngle    // 画像の回転角度 (見た目の向きのみ)
x, y           // 現在のX, Y座標
tx, ty         // ターゲット(相手)のX, Y座標
player_x, player_y // プレイヤーの座標(絶対座標)
dist           // 相手との直線距離
second, timer  // 経過秒数 (弾は発射から、コアはカード開始から)
frame          // 経過フレーム数
cardSecond     // 【弾側】カード開始からの秒数
cardFrame      // 【弾側】カード開始からのフレーム数

// --- 弾側専用の変数 ---
ex, ey         // 发射台(エミッター)の位置
e_変数名       // コア側のカスタム変数 (例: e_xspa)
color          // 弾の色コード
laserWidth     // レーザーの現在の太さ

// --- 衝突・状態判定 (0 または 1) ---
isBounced      // bounce() で壁反射した瞬間
isTouchWall    // 壁に衝突した瞬間
touchingWall   // 壁に接触中
leftWall, rightWall, topWall, bottomWall // 各壁の接触状態
isTouchBullet  // 他の弾に衝突した瞬間
touchingBullet // 他の弾に接触中
touchColor     // 接触した弾の色
touchX, touchY // 接触した弾の位置
パラメータの選択肢 & 組み込み関数
// 【画像の種類】
"none" (丸ドロー), "marutama" (丸弾), "kome" (米弾), "ootama" (大玉), 
"poihuru" (ポイフル), "star" (星), "uroko" (鱗), "virus" (ウイルス), 
"onmyoutama" (陰陽玉), "knife" (ナイフ), "ohuda" (お札)

// 【座標モード】
"relative" // 発射台の動きに合わせて弾も一緒に動く (相対)
"absolute" // 発射後は発射台が動いても弾は独立して進む (絶対)

// 【組み込み数学関数】
random()        // 0.0 以上 1.0 未満の乱数
random(max)     // 0 から max 未満の乱数
random(min,max) // min から max 未満の乱数
rand()          // random の略称 (同じ動作)
sin(度)         // 正弦 (サイン, 度数法)
cos(度)         // 余弦 (コサイン, 度数法)
tan(度)         // 正接 (タンジェント, 度数法)
sqrt(値)        // 平方根
abs(値)         // 絶対値
min(a, b)       // 小さい方の値
max(a, b)       // 大きい方の値
PI, PI2         // 円周率 (3.1415...), 2倍円周率 (6.283...)
自作カードの制限 & 実装例
【カード装備の制限】
自作カード ＋ アビリティカード  : 同時装備 OK
自作カード ＋ 通常アクティブカード : 同時装備 NG (同時発動不可)

【実装例: 敵に向かって撃ちながら左右にスライドする発射台】
while (true) {
    slideTo("farLeft", 1.0)
    wait(1.5)
    slideTo("farRight", 1.0)
    wait(1.5)
}
while (true) {
    aimAtTarget()
    spawnWay("normal", "#33ffff", 220, angle, 5, 15)
    wait(0.12)
}
