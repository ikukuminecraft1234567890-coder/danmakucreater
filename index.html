自作カード管理

Scratch風のエディットでオリジナルのスペルカードを作成できます。
作ったカードは「弾幕をプレイ」で確認し、すぐに登録可能です。

スペルカード編集

合計コスト: 0 / 30
制御 (Control)
変数 (Variables)
動作 (Motion / Actions)

自作弾幕コードヘルプ

よく使う時間・加速
// 弾側: 時間が経つほど加速
speed += timer * 0.2

// コア側で弾ごとに値を渡す
accelRank = 3
spawnWay("normal", "#33ffff", 250, angle, 1, 10)

// 弾側: 渡された値で加速差を作る
speed += timer * accelRank * 0.08

timer はその弾が出てからの秒数です。second はカード開始からの秒数、frame は毎フレーム増える値です。

自作カードの発動制限
自作カード + アビリティカード: OK
自作カード + 通常アクティブカード: NG

自作カードを選んだ時は、他の通常アクティブカードとは同時発動できません。アビリティカードは同時に使えます。

基本形
for (let i = 0; i < 10; i++) {
    // 10回実行
}

while (true) {
    // アクション中ずっと実行
}

if (条件) {
    // 条件が true の時だけ実行
}

wait(0.5) // 0.5秒待つ

一番上に複数の while (true) や for を置くと、同時に並行して動きます。古い forever() / repeat() もそのまま使えます。

エミッター側
aimAtTarget()
spawnBullet("normal", "#ff3333", 200, angle)
spawnRing("normal", "#33ffff", 180, 24)
spawnWay("normal", "#ff3333", 250, angle, 5, 20)

moveTo("center")
moveTo("right")
moveTo("left")
moveTo("farRight")
moveTo("farLeft")
moveTo("rightUp")
moveTo("leftUp")
slideTo("farRight", 0.5)

// 変数のスムーズ移行 (非同期で移行します)
tween("angle", 0, 360, "seconds", 1)  // 秒で移行
tween("speed", 100, 300, "frames", 60) // フレームで移行
tween("angle", 0, 180, "step", 5)      // 毎フレーム加算移行

// 変数のスムーズ移行完了を待つ (移行が終わるまで一時停止します)
tweenWait("angle", 0, 360, "seconds", 1)

moveTo は即移動、slideTo は指定秒数で滑らかに移動します。tween は非同期に変数を移行し、tweenWait は移行完了を待ってから次の行に進みます。

弾側
speed += 10
speed -= 5
speed = 300
angle += 2
angle = angle + random(-5, 5)
color = #33ffff

aimAtTarget()
homing(90)
bounce()
slow(0.5, 0)
fast(2, 0)

if (isBounced) {
    color = #ffdd33
}
if (touchingBullet) {
    if (touchColor == #ff3333) {
        y = 999999
    }
}

弾側コードは、発射された弾1つ1つの目線で毎フレーム動きます。

変数と条件
angle      // 角度
speed      // 速度
x, y       // 現在位置
ex, ey     // 送信機（エミッター）の位置
e_変数名   // 送信機のカスタム変数のリアルタイム値 (例: e_xspa)
tx, ty     // 相手の位置
player_x   // プレイヤーのX位置
player_y   // プレイヤーのY位置
dist       // 相手との距離
timer      // その弾の経過秒
second     // 秒数
frame      // フレーム数
color      // 色
isBounced  // bounceで跳ねたら1
isTouchBullet   // 弾に触れた瞬間だけ1
touchingBullet  // 弾に触れている間1
touchColor      // 触れた弾の色

random()        // 0から1
random(100)     // 0から100
random(-5, 5)   // -5から5

条件は if (speed > 300) や if (color == #33ffff) のように書けます。

例: 移動する発射台
while (true) {
    slideTo("center", 0.5)
    wait(2)
    slideTo("farRight", 0.5)
    wait(0.7)
    slideTo("center", 0.5)
    wait(2)
    slideTo("farLeft", 0.5)
    wait(0.7)
}

while (true) {
    aimAtTarget()
    angle += random(-8, 8)
    spawnWay("normal", "#33ffff", 360, angle, 5, 12)
    wait(0.08)
}
